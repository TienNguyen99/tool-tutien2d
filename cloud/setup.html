Kết nối Tiên Lộ với game

Dùng Chrome hoặc Edge trên máy tính. Không cần mở server.

Tải extension
  1. Giải nén file vừa tải

    Giữ lại thư mục extension trên máy.

  2. Nạp vào trình duyệt

    Mở chrome://extensions hoặc edge://extensions. Bật Chế độ nhà phát triển → Tải tiện ích đã giải nén → chọn thư mục extension.

  3. Kết nối trong game

    Mở game, đăng nhập rồi bấm ✦ Tiên Lộ. Nhập key bạn được cấp trên dashboard.

Khi cập nhật hoặc chưa kết nối được

Nạp lại extension và tải lại tab game. Sau đó bấm ✦ Tiên Lộ để kết nối lại.
